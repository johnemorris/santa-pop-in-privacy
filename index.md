# Privacy Policy – Santa Pop-In

Santa Pop-In does not collect, store, transmit, or share any personal data.

The extension only stores a single setting indicating whether the Santa animation is enabled or disabled. This setting is stored locally using Chrome’s storage API and is not shared with any third parties.

Santa Pop-In does not track browsing activity, read webpage content, inject advertisements, or collect analytics.

No data is sold, transferred, or used for purposes outside the functionality of the extension.
